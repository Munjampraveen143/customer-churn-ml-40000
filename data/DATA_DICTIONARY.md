# Data Dictionary

| Column | Description |
|---|---|
| customer_id | Unique synthetic customer identifier |
| gender | Customer gender |
| age | Customer age |
| senior_citizen | 1 if age >= 60 else 0 |
| partner | Whether customer has a partner |
| dependents | Whether customer has dependents |
| tenure | Months with company |
| phone_service | Phone service subscription |
| internet_service | Internet service type |
| online_security | Online security subscription |
| online_backup | Online backup subscription |
| device_protection | Device protection subscription |
| tech_support | Technical support subscription |
| streaming_tv | Streaming TV subscription |
| streaming_movies | Streaming movies subscription |
| contract | Contract type |
| paperless_billing | Paperless billing enabled |
| payment_method | Payment method |
| monthly_charges | Monthly recurring charge |
| total_charges | Total customer charges |
| support_tickets | Number of support tickets |
| late_payments | Number of late payments |
| satisfaction_score | Synthetic 1-10 satisfaction score |
| churn | Target: 1 churned, 0 retained |
